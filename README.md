# NeoCrunch - Proyecto futurista para vender frituras

Landing page futurista y responsive para promocionar y vender frituras con un simulador de pedido interactivo.

## Archivos

- index.html: estructura principal de la web
- styles.css: estilos visuales futuristas, animaciones y responsive
- app.js: logica del simulador de pedido y promo automatica

## Como usar

1. Abre index.html en tu navegador.
2. Explora el menu y usa el simulador para agregar productos.
3. Si agregas 3 o mas productos, se aplica la promo Neon (12%).
